# 猫的第九次散步

无需安装依赖的本地 Canvas 横版游戏，三章共 9 个长关卡：林间散步、潮汐码头、月下屋顶。原 24 小关已整理成连续段落，最新合并安排见 LONG-LEVELS.md；旧规划保留供参考。

直接打开 index.html 即可离线游玩。也可在此目录执行：

    node serve.cjs

然后访问 http://127.0.0.1:4173/ 。关闭服务器终端会停止服务。

## 手机试玩

手机与电脑连接同一局域网。在此目录执行：

    node serve.cjs --lan

手机浏览器打开终端列出的实际以太网或 Wi-Fi 地址（不要选 VPN 或虚拟网卡地址，也不要使用 localhost）。若 4173 已被旧服务占用，先停止旧服务，或在 PowerShell 中设置 $env:PORT='4174' 后执行上述命令。仅四个游戏静态文件会被提供，不提供源码目录列表。

推荐横屏：左手方向，右手跳跃；可同时按住。轻触小跳，长按大跳。重试按钮从最近路灯复活。全屏包含操作按钮；不支持原生全屏时使用页面展开模式。切换应用或旋转屏幕会暂停，点击“继续散步”恢复。

电脑需保持开机和服务运行。局域网若启用了设备隔离，或系统防火墙阻止该端口，手机可能无法连接；本工程不会自动修改防火墙。离开局域网也能访问需要另行部署到 HTTPS 托管服务，本版本尚未部署。

操作：A/D 或左右键移动；空格/W/上键跳跃（松开缩短跳跃）；R 从路灯重试；Esc 暂停。触屏按钮在触屏设备显示。

第一关只教学跳跃与一块裂纹板：桥板在踩上 1.15 秒后消失，下方小路可以补救；后续关卡按设计使用 0.65–0.9 秒。桥板死亡后复原。红色荆棘与飞果会造成死亡。路灯需实际落地后激活。鱼干为可选收集，不影响通关。

点击“选关”可切换三章，每章三个长关。每章首关直接开放，章内完成一关解锁下一关，可重玩已解锁关卡。原短关的解锁和通关状态会映射至对应长关；迁移使用独立存档键，不覆盖旧存档。最近选择的关卡可继续，关内位置与计时不保存。选择关卡从该长关起点出发，关闭菜单则保留暂停状态。

地图长约 2100–3530 世界单位，镜头仍保持近景。内部段落间连续通行、不弹结算。多个路灯在段落中和段落入口记录复活位置；旧桥的预警时间和风区位置保留，底部细条显示当前路程。

第二章：风区只在空中影响水平位移；蓝色弹性垫上长按跳跃可跳得更高。第三章：浅蓝冰面有滑行惯性，按反方向可刹车；箭头传送带只在落地时推动角色。均使用原来的方向键与跳跃键，无需新按键。

线上试玩：https://isaac-cui.github.io/cat-walk/ 。第一关的设计预算与真人试玩记录见 PLAYTEST.md；真人试玩尚未完成。

视觉由本地 Canvas 绘制，包括缓存的纸张颗粒、树林和曲线山丘；没有使用 AI 生成图或外部美术素材。音效由 Web Audio 合成，不包含背景音乐。

验证：node test-game.cjs
